# three.js

![threelearning](https://github.com/user-attachments/assets/0608738d-4f0e-401a-b91f-dced6611f1b4)

This code builds an interactive 3D scene using Three.js. It displays four geometries (like a torus and octahedron) and floating particles. Users can rotate the objects with the mouse wheel and control the camera position with mouse movement. The appearance is customizable in real-time using lil-gui, allowing adjustments to material properties like color, metalness, and roughness. Animations are smoothly handled using requestAnimationFrame and time deltas for consistent motion.
